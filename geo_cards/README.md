# ساخت پست «سؤال روز»

هر سؤال را چند بار از هوش مصنوعی می‌پرسد، می‌شمارد اسم چه کسانی در جواب‌ها آمد و به کدام سایت‌ها ارجاع شد، و پست آماده‌ی انتشار می‌سازد. ادمین فقط آهنگ را داخل اینستاگرام اضافه می‌کند.

## خروجی هر سؤال

| فایل | کاربرد |
|---|---|
| `post/*.png` | کاروسل اینستاگرام، ۱۰۸۰ در ۱۳۵۰ |
| `story/*.png` | همان اسلایدها برای استوری، ۱۰۸۰ در ۱۹۲۰ |
| `reel.mp4` | ریلز بی‌صدا از اسلایدهای استوری |
| `private/*.png` | نتیجه بدون تار، فقط برای ارسال خصوصی به خود پزشک |
| `caption.txt` | کپشن اینستاگرام با هشتگ |
| `linkedin.txt` | متن پست لینکدین |
| `virgool.md` | پیش‌نویس مقاله‌ی ویرگول |
| `data.json` | همه‌ی جواب‌ها و شمارش‌ها، سند کار |
| `html/` | فایل طراحی هر اسلاید، اگر خواستی دستی چیزی را عوض کنی |

اسلایدها به ترتیب: سؤال، جواب هوش مصنوعی با تعداد حضور هر اسم، سایت‌هایی که به آن‌ها ارجاع شد، ۳ کار پیشنهادی، دعوت به تست رایگان.

## نصب (یک بار، روی مک)

از پوشه‌ی پروژه:

```bash
.venv/bin/pip install -r geo_cards/requirements.txt
cp geo_cards/.env.example geo_cards/.env
brew install ffmpeg        # فقط برای ساخت ریلز
```

بعد کلید `OPENAI_API_KEY` را در `geo_cards/.env` بگذار. اگر از درگاه ایرانی سازگار با `OpenAI` استفاده می‌کنی، آدرسش را در `OPENAI_BASE_URL` بنویس.

تصویرها با همان `Google Chrome` روی مک ساخته می‌شوند و نصب چیز دیگری لازم نیست.

## اجرای روزانه

```bash
.venv/bin/python -m geo_cards list                       # فهرست ۶۰ سؤال
.venv/bin/python -m geo_cards run --id 1                 # یک سؤال
.venv/bin/python -m geo_cards week --start 1 --count 7   # سؤال‌های یک هفته
```

سؤال دلخواه:

```bash
.venv/bin/python -m geo_cards run --q "بهترین دندانپزشک کرمان کیست؟" --category medical --city کرمان
```

خروجی در پوشه‌ی `geo_cards/output` ساخته می‌شود؛ هر سؤال یک پوشه.

## حالت دستی (بدون API)

سؤال را چند بار در اپ `ChatGPT` بپرس، هر جواب را در یک فایل متنی کپی کن و بین جواب‌ها یک خط فقط با `---` بگذار:

```bash
.venv/bin/python -m geo_cards run --id 1 --import answers.txt
```

روی پست نوشته می‌شود «در اپ». این معتبرترین حالت است، چون دقیقا همان چیزی است که کاربر می‌بیند.

## انتشار

- کاروسل: عکس‌های پوشه‌ی `post` را به ترتیب آپلود کن، آهنگ ترند را از داخل اینستاگرام اضافه کن، کپشن را از `caption.txt` بردار.
- ریلز: `reel.mp4` را آپلود کن و آهنگ را داخل اینستاگرام بگذار. آهنگی که داخل خود اینستاگرام انتخاب شود هم ترند حساب می‌شود و هم مشکل کپی‌رایت ندارد.
- اگر آهنگ مجاز خودت را داری: `--music song.mp3`
- لینکدین: متن `linkedin.txt` را بردار و جای `[یک جمله برداشت خودت]` یک جمله بنویس.
- ویرگول: `virgool.md` را کامل کن. آخر ماه این دستور همه‌ی سؤال‌ها را در یک مقاله جمع می‌کند:

```bash
.venv/bin/python -m geo_cards roundup --since 2026-10-01
```

## اصلاح بعد از ساخت

اگر اسمی اشتباه استخراج شد یا دو اسم باید یکی شوند، `data.json` همان پوشه را ویرایش کن و بدون پرسیدن دوباره بساز:

```bash
.venv/bin/python -m geo_cards render geo_cards/output/<اسم پوشه>
```

## طراحی

رنگ‌ها، آیدی پیج، متن دعوت و لوگو در `config.yaml` است. تعداد تکرار هر سؤال (`runs`) و تعداد اسم روی اسلاید (`top_n`) هم همان‌جاست. کد طراحی در `design.py` است.

## قانون‌های سری

- اسم پزشک‌ها روی پست عمومی خودکار تار می‌شود. نسخه‌ی `private` فقط برای ارسال خصوصی به خود پزشک است.
- اسم وکیل‌ها را نیاور.
- جواب هوش مصنوعی را دستکاری نکن. `data.json` سند هر پست است.
- روی پست نوشته می‌شود چند بار، از کدام مدل و با یا بدون جستجوی وب پرسیده شد. این را پاک نکن.

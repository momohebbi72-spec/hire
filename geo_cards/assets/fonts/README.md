# فونت

فونت وزیرمتن (`Vazirmatn`) با مجوز آزاد `OFL` (فایل `OFL.txt`) کنار همین فایل است و داخل هر اسلاید جاسازی می‌شود؛ پس ساخت تصویر به اینترنت نیاز ندارد.

برای فونت دیگر، فایل `woff2` یا `ttf` آن را اینجا بگذار و اسمش را در `config.yaml` جلوی `font_family` بنویس. وزن فونت از اسم فایل خوانده می‌شود (`Regular` و `Bold` و `Black` و…).
